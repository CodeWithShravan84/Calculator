# Calculator App 🧮

A simple, efficient, and user-friendly calculator application. 

## 🌟 Features
* **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
* **Clear Interface:** Easy to read and navigate.
* **Error Handling:** Gracefully handles edge cases like division by zero.
* **Themes** It has Light theme and Dark theme.

## 🛠️ Technologies Used
* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose
* **Architecture:** MVVM (Model-View-ViewModel) with MVI-style intent commands
* **Math Evaluation:** mXparser library
